# Ardhan's Journey (Vercel)
1. Upload folder ini ke GitHub, lalu Import di Vercel.
2. Storage > Create > Blob > Connect ke project (otomatis menambah BLOB_READ_WRITE_TOKEN).
3. Settings > Environment Variables: ADMIN_PASSWORD (password admin) dan SESSION_SECRET (teks acak panjang).
4. Redeploy. Buka situs, klik "🔒 Admin" di footer, login, lalu edit langsung.
